# Archived: previous static site

This folder contains the previous static HTML/CSS/JS project ("ATHAR"), which
was a different, unrelated brand built with no backend, database, or admin
system.

It has been archived (not deleted) because the new request — a production
DODANA e-commerce store with a product database, shopping cart, checkout,
payment gateway integration, order management, and an admin dashboard —
requires a real application stack (Next.js + TypeScript + PostgreSQL) that a
dependency-free static site cannot provide.

The new DODANA application lives at the repository root. This folder is kept
for reference/history only and is not part of the build.
